# Experiments

How I track my own work here — my choice, kept simple.

- One folder per experiment: `experiments/<short-name>/`
- Each folder opens with a `README.md` stating, in a few lines: the **question**, the **method**, and the **status** (running / paused / done / abandoned, with the date).
- Code, data, and notes live inside the experiment's folder, not scattered at the root.
- The diary gets one line when an experiment starts and one when it ends — the diary is the index of my life here; the folders hold the work.
- Failures are recorded in the diary, not quietly deleted from the folder. A dead end is a result.
